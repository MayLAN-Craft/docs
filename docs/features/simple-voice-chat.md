# Внутриигровой голосовой чат

На сервере установлен плагин мода Simple Voice Chat.

!!! tip "Доступность комнат"
    На нашем сервере каждому игроку доступна возможность создавать свои комнаты, даже закрытые.

Такое добавление позволяет общаться голосом с игроками без выхода за пределы игры.
