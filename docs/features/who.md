# Контактная информация

**MaylanSocial** — это плагин, который позволяет игрокам делиться своими контактами и профилями в социальных сетях. С его помощью вы можете привязать к своему игровому аккаунту Telegram, Discord, Steam, YouTube и другие сервисы, а также быстро узнать контакты любого другого игрока на сервере.

---

## ⌨️ 1. Основные команды

Все команды разделены на управление собственным профилем (`/social`) и просмотр профилей других игроков (`/who`):

| Команда | Действие | Описание |
| --- | --- | --- |
| **`/social`** | **Справка** | Показывает краткое меню со списком команд настройки. |
| **`/social show`** | **Мои соцсети** | Выводит список всех ваших привязанных контактов. |
| **`/social set <тип> <значение>`** | **Привязать соцсеть** | Устанавливает ссылку, юзернейм или ID для выбранной платформы. |
| **`/social clear <тип>`** | **Удалить соцсеть** | Очищает сохранённые данные указанной платформы. |
| **`/who <ник>`** | **Профиль игрока** | Показывает карточку социальных сетей указанного игрока. |

---

## 📱 2. Поддерживаемые платформы и сокращения

При привязке вы можете использовать как полное название платформы, так и удобные короткие алиасы (сокращения):

| Платформа | Тип для команды | Что можно вводить | Сокращения (Алиасы) |
| --- | --- | --- | --- |
| **Discord** | `discord` | Никнейм, ID пользователя или ссылка | — |
| **Telegram** | `telegram` | Юзернейм (например, `username` или `@username`) | — |
| **Steam** | `steam` | Ссылка на профиль, SteamID64 или кастомный URL | — |
| **Twitch** | `twitch` | Никнейм стримера (`@username`) или ссылка | — |
| **YouTube** | `youtube` | Хэндл (`@channel`), ссылка на канал | **`yt`** |
| **TikTok** | `tiktok` | Юзернейм (`@username`) или ссылка | **`tik`** |
| **Веб-сайт** | `website` | Адрес сайта (например, `mysite.ru` или полная ссылка) | **`site`**, **`web`** |

---

## 🔍 3. Просмотр контактов других игроков (`/who`)

Команда **`/who <ник_игрока>`** выводит в чат интерактивную карточку с контактами пользователя. Все ссылки в ней кликабельны:

* 🔗 **Открытие страниц:** Клик по названию Telegram, Steam, Twitch, YouTube, TikTok или Сайта автоматически откроет соответствующий профиль в вашем браузере.
* 📋 **Копирование:** Если игрок указал Discord в виде текстового никнейма, клик по нему автоматически скопирует логин в буфер обмена.
* 💡 **Подсказки:** При наведении курсора на ссылку в чате появится всплывающее окно с подсказкой о действии.

## 🛠️ 4. Примеры использования

### Как привязать соцсети:

* **Telegram:** `/social set telegram @my_telegram`
* **YouTube (используя алиас):** `/social set yt @my_channel`
* **Discord (по ID или логину):** `/social set discord my_username`
* **Личный сайт (используя алиас):** `/social set site my-website.ru`

### Как удалить привязку:

* **Удалить Telegram:** `/social clear telegram`
* **Удалить Сайт:** `/social clear site`

## ❓ 5. Часто задаваемые вопросы (FAQ)

* **Обязательно ли заполнять все соцсети?**
    * Нет, вы можете привязать только те контакты, которыми хотите поделиться. Если платформа не указана, у других игроков она будет отображаться со статусом «не указано».


* **Как изменить уже привязанную соцсеть?**
    * Просто введите команду `/social set <тип> <новое_значение>` заново — старые данные автоматически перезапишутся.


* **Видят ли мои соцсети другие игроки?**
    * Да, любой игрок на сервере может ввести команду `/who <ваш_ник>` и посмотреть указанные вами контакты. Указывайте только ту информацию, которой готовы делиться публично.
