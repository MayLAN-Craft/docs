# MayLAN Craft

**MayLAN Craft** — это приватный ванильный сервер Minecraft для комфортной игры в приятной компании. Проект работает на актуальной версии **26.2+**.

---

## 📌 Что нужно знать о сервере

<div class="grid cards" markdown>

- :material-cube:{ .lg .middle } **Ванильный сервер**

    ---
    Никаких `/god`, `/fly` и других дисбалансных команд. Только чистый игровой процесс!

- :material-pirate:{ .lg .middle } **Доступен всем**

    ---
    Сервер пиратский, но для владельцев лицензии доступен авто-вход без ввода пароля.

- :lucide-earth-lock:{ .lg .middle } **Без приватов**

    ---
    Никаких сложных приват-зон. Защиту и откат территории обеспечивает CoreProtect.

- :lucide-brush-cleaning:{ .lg .middle } **Без частых вайпов**

    ---
    Мир сохраняется максимально долго. С выходом новых версий мы просто расширяем границы.

- :material-cash-off:{ .lg .middle } **Без донатов**


    ---
    Никакого Pay-to-Win или покупки привилегий. Все игроки находятся в равных условиях.

-  :lucide-infinity:{ .lg .middle } **Долговечный проект**
    
    ---
    Хостинг проплачен на 30+ месяцев вперёд. Сервер не закроется ни через месяц, ни через год.
